# codeAlpha_Social_Media_Platform

Togetherly – Modern Social Media Dashboard

Togetherly is a web-based social media application where users can create accounts, share posts, interact with other users, and discover people through a simple social feed.
The application includes user registration and login, a personalized profile, post creation, a social feed, likes and comments, user search, and follow functionality.



✨ Features

- Auth Screens: Clean, centered forms for user Login and Registration with custom high-contrast highlights.
- Interactive Feed:** View community posts, interact with live updates, and explore a structured social layout.
- Personal Journal & Profile: Manage personal posts, track followers, and customize your profile interface.
- User Discovery Search: Real-time floating search dropdown to locate other users and connect instantly.
- Easy-on-the-Eyes Theme: Carefully calibrated deep midnight violet (`#181022` to `#0a080e`) gradients and subtle borders.
